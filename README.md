# 飙飙的小家

一个以猫咪飙飙为主角的离线陪伴与收藏小应用。

飙飙是我朋友 Sherry 家的小猫，是银渐层和缅因猫的混血。Sherry 外出上学时，飙飙就通过这个小应用陪在她身边。

飙飙可以待在桌面上，也有自己的小家。你可以喂它吃零食、陪它玩，收集日常和旅行明信片，用家具和不同背景布置房间。

## 功能

- 桌面小猫，可拖动位置并打开小家。
- 喂食、玩具互动，以及随当地时间变化的日常状态。
- 明信片收藏，包含居家、旅行和节日主题。
- 家具、背景与手信置物架。
- 合成大飙飙小游戏。
- 本地保存收藏和游戏进度。

## 平台

- Windows 桌面版，当前版本 1.0.9。
- Android 版，当前版本 1.0.2。
- Mac 版正在准备，原生构建与实机验证待完成。
